# Project Brief

## Goal

Build and customize a Shopify Horizon theme into a premium-style ecommerce theme, step by step, without copying licensed premium theme code or assets.

## Base

- Theme family: Shopify Horizon-style theme
- Active theme folder: `horizon-source/new1-premium-announcement-bar`

## Priorities

- Fast loading
- Mobile-first UX
- Clean, readable code
- Shopify Theme Editor compatibility
- Conversion-focused sections
- Reusable snippets and maintainable assets
- Clear Git history after each working feature

## Build Style

Work one feature at a time. For each feature:

1. Read the relevant docs.
2. Inspect existing theme files.
3. Identify all related Liquid, CSS, JS, config, and schema files.
4. Make focused changes.
5. Test locally with Shopify CLI where possible.
6. Summarize changed files and next steps.

# AI Working Rules

- The user may give instructions in Roman Urdu/Hindi. Interpret the business goal, then implement the technical work in the Shopify theme.
- Keep explanations simple for the user, but handle technical details professionally.
- Before editing, inspect the theme structure and existing patterns.
- Prefer existing theme conventions over new architecture.
- Do not make unrelated refactors.
- Do not delete user work unless clearly instructed.
- For feature work, update all relevant connected files, not only one isolated file.
- Keep code readable for future AI and human developers.
- When a Shopify store domain is needed, ask the user for the `.myshopify.com` domain.

# Feature 03: Homepage

## Goal

Create premium-style homepage sections while keeping the implementation original and Shopify Theme Editor friendly.

## Candidate Sections

- Hero/banner section
- Featured collections
- Featured product grid
- Promo tiles
- Trust badges
- Testimonials/reviews
- Image with text

## Rules

- Build one section at a time.
- Use schema settings for merchant editing.
- Keep mobile layout strong before desktop polish.

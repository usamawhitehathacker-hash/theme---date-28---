# Feature 02: Header And Mega Menu

## Goal

Build a premium-style header and mega menu using an original implementation that follows the existing theme structure.

## Requirements

- Sticky header support
- Logo support
- Desktop navigation
- Mega menu blocks where appropriate
- Search entry point
- Account link if enabled
- Cart icon/count
- Mobile drawer navigation
- Accessible keyboard/focus behavior
- Theme Editor settings/schema compatibility

## Rules

- Do not copy paid theme code.
- Inspect existing header, menu, drawer, icon, and asset files before editing.
- Keep CSS and JS scoped and minimal.

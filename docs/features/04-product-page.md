# Feature 04: Product Page

## Goal

Improve the product page with premium ecommerce UX using original code.

## Candidate Features

- Product media gallery
- Variant swatches
- Sticky add to cart
- Product information tabs
- Size chart
- Trust badges
- Cross-sell/upsell blocks

## Rules

- Inspect current product templates, sections, snippets, and assets first.
- Keep variant behavior compatible with Shopify.
- Avoid unnecessary JavaScript.
